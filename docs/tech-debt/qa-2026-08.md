## Топ к фиксу (в порядке приоритета)

1. **#23 Б** `PATCH /api/learn/employees/{id}` без смены орг-полей → **500** `UnboundLocalError: 'diffs'` (`app/api/employees.py:288`): `diffs` присваивается только в ветке `org_changed and status == 'active'`, а `notify_new_audience_members(db, diffs)` зовётся всегда. Ломает выдачу `content_role` publisher существующему сотруднику, правку имени/телефона/`status_text` из «Управление → Сотрудники».
2. **#20 В** Смена состава группы (`PUT /learn/org/user-groups/{id}/members`) не пересчитывает `audience_members`: курс с аудиторией «группа» не появляется у нового члена, пока админ не дёрнет `POST /learn/audiences/rebuild` (`audiences_changed: 1`). Прямой GET курса при этом 200.
3. **#24 В** «Управление» у `org_role ∈ {office, tu}` без `content_role=publisher`: фронт (`adminSegmentsFor`, `learnNav.ts`) рисует пункт и вкладки «Проверка»/«Аналитика», бэк отдаёт 403 (`quizzes.py` review-queue требует publisher; `learn_analytics.py` — publisher или скоуп) → красный «Не удалось загрузить». Для ТУ «Аналитика» работает (скоуп магазинов), «Проверка» — нет.
4. **#22 В** У редактора проекта (`can_edit && !can_manage`) нет меню «Действия» (…) → «Импорт из CSV…» недостижим в непустом проекте.
5. **#8 В / #6 К** После импорта CSV метки на строках не видны до F5 (`['label-assignments']` не инвалидируется); шапка проекта держит «0 задач» до рефетча списка проектов после создания задачи.
6. **#27 В** Уведомления о сменах пишут время в UTC («Вы назначены на смену 30.08 08:00–16:00 UTC» при 10:00–18:00 в интерфейсе) + форма «откликнулся(-ась)».
7. **#16 В** Ассистент: «Сегодня, **1 1 операция**» — `plural()` уже содержит число, снаружи добавлено ещё раз.
8. **#13 В** Проект на телефоне: шапка (ключ, название, бейдж, описание, счётчики) + 5 фильтров в 3 ряда занимают ~550px из 844 — в макете «Доска · мобильный» компактная шапка без фильтров, колонки с ~140px.
9. **#14 В** Карточка задачи на телефоне: кастом-поля — стопка «подпись + инпут», в макете — те же `PropertyRows` 48px, что Этап/Приоритет/Срок; кнопка «Закрыть» получает фокус-ринг при открытии.
10. **#25 В** Витрина сотрудника без блока «Моё обучение» (назначенные курсы с прогрессом, «Все N курсов →») — есть только «Сейчас важно» и «Новинки».
11. **#9 В** Шапка списка при 7 CF-колонках: подписи колонок налезают друг на друга (нет `truncate`); **#19 В** топбар конструктора курса шире 1280 (`main` scrollWidth 1019 > 973) → горизонтальный скролл.

## Не проверено (и почему)

Push живьём (разрешение браузера в MCP-профиле); микрофон и iOS-PWA (safe-area, печать сертификата) — только руками владельца; `Donut` в Safari; прохождение реальных опросов и ack реальных материалов под персонами (засорили бы агрегаты UPPETIT); сертификат и аттестации для QA-аудитории не создавались; роль франчайзи на проде не существует; 16 диалогов авторского контура открыты выборочно; touch-DnD (только pointer-эмуляция). Скриншоты смотрелись инлайн и на диск не сохранялись — при необходимости переснять по номеру находки.
