# Экраны без макета — задание на дорисовку (ревизия 2026-08-21)

Первая версия этого документа (2026-08-20) перечисляла 20 экранов, которых не было в макетах
Claude Design. Дизайнер дорисовал их тем же днём — `redesign/` обновлён целиком (пять `.dc.html`).
План доведения продукта — `~/.claude/plans/claude-design-iridescent-gray.md` (шесть волн), решения
владельца: этапы доски — новая сущность, дашборд и learn-аналитика без recharts, «Управление» —
один маршрут с шестью сегментами, импорт CSV — в плане.

Ниже — текущее состояние: что закрыто, что нарисовано и ждёт реализации, чего в макетах нет
по-прежнему, и где продукт сознательно отступает от макета.

## Нарисовано, но отложено (мелкая полировка)

- Урок на телефоне: двухстрочная PDF-панель, галерея 248×186, play 60/68 (текущие размеры близки).
- Библиотека: «Изучить по теме» в карточке документа (связи материал↔курс в модели нет).
- Курс: строка «Для кого» в рельсе (человекочитаемой аудитории в ответе курса нет).
- Сертификат: серверный PDF / «Отправить PDF» с телефона — сейчас печать браузером и
  полноэкранный просмотр.

## По-прежнему без макета

- `/search` — поиск с DSL-чипами (открывается по ⌘K).
- `/p/:token` — анонимный просмотр по публичной ссылке.
- Управление кампаниями аттестаций (создание, аудитория, импорт вопросов) — только участник нарисован.
- Редактор урока как рабочий экран (панель свойств, медиа, PDF-режим) — в макете каркас конструктора.
- Диалоги и оверлеи без маршрута: создание задачи/проекта/папки, пикер зависимостей, настройки
  колонок, «Поделиться» — собраны из общих примитивов, отдельно не нарисованы.

## Осознанные отступления от макетов (не дорисовывать, не править)

- Таб-бар 56px / подпись 11px (макет 50/10) — правило «ниже 12px ничего, исключение — 11px таб-бара».
- Вкладка «Участники» проекта остаётся шестой; фильтр «Срок» и стрелка сортировки в тулбаре остаются.
- Пагинации списка задач нет: список грузится целиком, «N из M» даётся серверными тоталами.
- Календарь/Хронология/Дашборд в макете «скоро» — в продукте работают и нарисованы по спеке.
- Ассистент: «Списания и потери», порог подтверждения, список разговоров, «В журнал» сверху.
- Сертификат: «Скачать PDF» на десктопе = печать браузером (A4 landscape); серверный PDF отложен.
- Импорт CSV — только фиксированный шаблон колонок и только с десктопа (в мобильной шапке нет меню
  действий; с телефона файлы не импортируют).
